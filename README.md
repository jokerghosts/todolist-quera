## 📌 About

**Quera Todolist** is an educational project designed and developed by our team as part of the [Quera Front-End Bootcamp](https://quera.org/bootcamp/front-end).

The main goal of this project was to practice and simulate working in a real software team: distributing tasks among members, collaborating with Git and GitHub (including working with branches, merging changes and Pull Requests) and applying web development concepts in a practical product. Throughout the project, the team mentor, a member of the Quera staff, provided guidance and technical consulting.

The application lets users record their daily tasks, prioritize them by importance and track their progress. The user interface is fully right-to-left (Persian) and optimized for different screen sizes.

***

## ✨ Features

- **Task management:** create, edit in place and delete tasks
- **Prioritization:** three priority levels (high, medium, low) with automatic sorting
- **Progress tracking:** completed tasks are listed separately and sorted by completion time
- **Local storage:** data is kept in the browser using `localStorage`
- **Light and dark themes:** the theme is applied before the page renders, with a smooth transition when switching
- **Responsive design:** optimized for mobile and desktop, with a slide-out menu
- **Persian interface:** fully right-to-left user interface

## ▶️ Getting Started

This project does not require any tools or dependencies to be installed. After cloning the repository, open `index.html` in your browser.

```bash
git clone https://github.com/jokerghosts/todolist-quera.git
```
